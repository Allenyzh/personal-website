MTLove is an interactive AI-powered dialogue game, built with a team at ConUHacks IX (Concordia University, Montreal) in February 2025.

## What I worked on

- Built the game with React, Vite.js, Zustand and React Router
- Engineered a responsive UI with Tailwind CSS that works across desktop and mobile
- Integrated AI-driven emotional analysis for dynamic, personalized player interactions
- Managed the real-time dialogue flow with Zustand
- Worked with the team to optimize AI response time and dialogue authenticity
